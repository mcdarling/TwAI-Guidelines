# TwAI Dictionary

**Artificial intelligence, machine learning, and trustworthy AI terms, with
definitions from the organisations that shape them.**

Standards bodies, regulators, and researchers define AI terms differently.
The differences matter: a system can be an “AI system” under one definition
and not another, and “fairness” names several criteria that cannot all be met
at once. So this dictionary gives **several definitions for each term**, each
tied to its source, instead of a single preferred one.

## How to read an entry

- A definition marked [quoted]{.kind .kind-quoted} is quoted verbatim from
  its source.
- A definition marked [adapted]{.kind} is paraphrased or condensed. Consult
  the source before citing it formally.
- Each source label is coloured by organisation and links to the full
  reference.
- A note after the definitions explains how they differ, and **See also**
  links to related terms.

Browse every term on the [A–Z list](generated/a-z.md), or see which
organisations define which terms on the [coverage table](generated/coverage.md).
Use the search box to find a term or phrase.

The whole dictionary is also available as a
<a href="twai-dictionary.pdf">PDF</a>.
